# \# GradeTracker

# 

# GradeTracker is a Student Performance Monitoring and Feedback System developed for CptS 322: Software Engineering Principles I at Washington State University.

# 

# \## Project Overview

# 

# GradeTracker is designed to help students and instructors monitor academic performance. Instructors will be able to enter assignment grades and feedback, while students will be able to view their grades, progress, and instructor feedback.

# 

# \## Core Features

# 

# \- Student and instructor accounts

# \- Course management

# \- Assignment management

# \- Grade entry

# \- Student grade viewing

# \- Instructor feedback

# \- Academic progress tracking
