\# Contributing



\## Workflow



1\. Create a branch for the feature or task.

2\. Make changes on the branch.

3\. Commit changes with clear commit messages.

4\. Push the branch to GitHub.

5\. Create a pull request.

6\. Review and merge the pull request into main.



\## Branch Naming



Examples:



\- feature/student-dashboard

\- feature/grade-entry

\- fix/login-error

\- docs/requirements



\## Guidelines



\- Avoid making major changes directly to main.

\- Keep commits focused on a specific task.

\- Use clear names for files, variables, classes, and functions.

\- Review changes before merging.

\- Communicate with team members before making major design changes.
